🚀 Inicio Rápido

Cuestionario AIE Premium con Claude AI + n8n

1️⃣

Obtener API Keys 10 min

Necesitas 3 credenciales para que todo funcione:

🔑 API Key de Claude

  • Ve a console.anthropic.com
  • Crea o inicia sesión
  • Click en "API Keys"
  • Click "Create Key"
  • Copia: sk-ant-...

🔗 Webhook de n8n

  • Entra a tu n8n
  • Crea nuevo workflow
  • Agrega nodo "Webhook" (POST)
  • Copia la URL completa

📧 Email de Contacto

  • Tu email: hello@azloom.tech
💡 Tip: Guarda estas 3 credenciales en un lugar seguro. Las necesitarás después.
2️⃣

Crear Cuenta en Vercel 5 min

Vercel es donde correrá tu formulario (¡es gratuito!):

  • Ve a vercel.com
  • Click "Sign Up"
  • Elige GitHub, Google o Email
  • Completa el registro
  • Verifica tu email
✓ Crear Cuenta en Vercel
3️⃣

Crear Repo en GitHub 5 min

GitHub almacena tu código y se conecta automáticamente a Vercel:

  • Ve a github.com/new
  • Nombre: aie-cuestionario-premium
  • Descripción: "Sistema de cuestionario con Claude AI"
  • Selecciona "Public"
  • Click "Create repository"
💡 Después de crear: GitHub te muestra comandos para subir el código. Guárdalos para el próximo paso.
🚀 Crear Repo en GitHub
4️⃣

Subir a GitHub 5 min

Copia tu código local a GitHub:

En tu terminal/PowerShell:
cd "C:\Users\nicolas\Desktop\clientes\AIE OS Presentacion" git remote add origin https://github.com/TU-USUARIO/aie-cuestionario-premium.git git branch -M main git push -u origin main
💡 Reemplaza: TU-USUARIO con tu usuario de GitHub
5️⃣

Conectar Vercel + GitHub 5 min

Vercel se conecta a tu repo de GitHub automáticamente:

  • Ve a vercel.com/new
  • Click "Continue with GitHub"
  • Autoriza Vercel
  • Busca y selecciona aie-cuestionario-premium
  • Click "Import"
  • Click "Deploy" 🚀
💡 Espera 1-2 minutos: Vercel despliega automáticamente. Verás tu URL al terminar.
→ Ir a Vercel
6️⃣

Agregar Variables de Entorno 3 min

Configura tus 3 API keys en Vercel:

  1. Ve a tu proyecto en Vercel dashboard
  2. Click "Settings" (arriba)
  3. Click "Environment Variables" (izquierda)
  4. Agrega estas 3 variables:
    • CLAUDE_API_KEY = sk-ant-...
    • N8N_WEBHOOK_URL = https://n8n...
    • CONTACT_EMAIL = hello@azloom.tech
⚠️ Importante: Después de agregar variables, haz "Redeploy": Settings → Deployments → Click en los 3 puntos (...) → "Redeploy"
7️⃣

Test del Formulario 5 min

Verifica que todo funciona:

  • Abre tu URL de Vercel en el navegador
  • Completa el formulario
  • Haz click "Enviar cuestionario"
  • Deberías ver "¡Gracias, Diego!"
  • Revisa tu email (puede ir a SPAM)
💡 Si hay error: Abre DevTools (F12) y revisa la consola o Network
8️⃣

Configurar n8n Workflow 15 min

Configura el flujo automático en n8n:

Opción Fácil: Importar

  • En n8n, click "Workflows"
  • Click "Import"
  • Sube n8n-workflow-template.json
  • Click "Import from file"

Si no funciona: Crear Manual

  • Nuevo Workflow
  • Agrega nodo Webhook (POST)
  • Agrega nodo Gmail o SendGrid
  • Autentica tu email
  • Configura el template del email
  • Activa el workflow
💡 Email Template: Mira el archivo DEPLOY-CHECKLIST.md para el HTML del email
